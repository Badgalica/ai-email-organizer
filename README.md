# AI Email Organizer

An AI-powered email assistant that helps users organize their inbox.

## Planned Features
- Automatically categorize emails
- Detect urgent messages
- Summarize long emails
- Suggest email replies
- Generate daily inbox summaries

## Technologies
- Python
- OpenAI API
- n8n
- GitHub

## Project Status
In development

## Goal
Build an intelligent email assistant that saves time and improves productivity.
